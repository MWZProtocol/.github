# Contributing to MWZProtocol

Thank you for your interest in contributing!

## For Team Members

See the private mwz-docs repository for development guidelines.

## For External Contributors

### SDK and Documentation

Contributions to public repositories welcome:

- [mwz-sdk](https://github.com/MWZProtocol/mwz-sdk/blob/main/CONTRIBUTING.md)
- [mwz-developer-docs](https://github.com/MWZProtocol/mwz-developer-docs/blob/main/CONTRIBUTING.md)

### Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request
5. Wait for review from maintainers

### Code of Conduct

Be respectful. No harassment, discrimination, or abuse.

## Development Setup

Public repositories use:
- TypeScript
- pnpm
- Turbo
- ESLint
- Prettier

## Questions?

Open a GitHub discussion or issue in the relevant repository.
