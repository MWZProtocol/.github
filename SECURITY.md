# Security Policy

## Reporting Security Issues

**Do NOT open public GitHub issues for security problems.**

Please email security@mwzprotocol.com with:
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)

## Response Timeline

We will:
1. Acknowledge receipt within 48 hours
2. Investigate and determine severity
3. Work on a fix
4. Coordinate disclosure timing
5. Credit the reporter (if desired)

## Scope

This policy applies to:
- Public SDK and documentation
- Integration APIs
- Smart contracts

## Out of Scope

- Social engineering
- Physical attacks
- Denial of service attacks on public services
